# UI test selectors

Shared UI accepts the standard `data-testid` prop. Use a unique, consumer-owned base per instance, e.g. `profile-email`, not a global fixed ID, translated label, array index or a CSS class. IDs are optional; the library emits no default test selectors. Root composition/provider components with no DOM (e.g. Dialog, FormSubmit) do not own a selector: put it on Content, the trigger or the rendered submit Button.

```tsx
<Input data-testid="profile-email" label="Email" />
<Select data-testid="profile-category" options={options} searchable />
<DatePicker data-testid="profile-date" />
<DataTable data-testid="orders" rows={rows} columns={columns} rowId={(row) => row.id} />
```

Prefer role/name/label queries when these describe the intended user action. Test IDs are an additional contract for repeated, localized or structurally complex controls. Playwright, Cypress and Testing Library can use the same `data-testid` attribute. Compound IDs do not change ARIA roles, form `id`/`name`, values or BE query keys.

## Selector targets

| API                                                                | Base ID target                                          | Important derived IDs                                                                                                                                                                                                                                             |
| ------------------------------------------------------------------ | ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Button, IconButton, Badge, Alert, Card, Skeleton, Breadcrumb parts | Native root                                             | Explicit IDs on any consumer-provided child controls                                                                                                                                                                                                              |
| Input, Textarea, InputPassword, NumberInput, InputOTP              | Actual native input/textarea                            | `-root`, `-label`, `-hint`, `-error`; Password `-toggle`; Number `-increase`, `-decrease`, `-stepper`; OTP `-slot-0` through `-slot-(length-1)`                                                                                                                   |
| Checkbox, Switch, RadioGroup                                       | Choice control / radio group                            | `-root`, `-label`; Radio `-optionControl-{value}`, `-optionLabel-{value}`                                                                                                                                                                                         |
| Select, TimePicker                                                 | React Select control wrapper; find its combobox by role | `-root`, `-menu`, `-option-{value}`, `-clear`, `-remove-{value}`, `-loadMore`, `-loadMoreKeyboard`, `-retry`, `-hint`, `-error`                                                                                                                                   |
| DatePicker, DateRangePicker                                        | Trigger button                                          | `-clear`, `-popover`, `-calendar`, `-calendar-day-YYYY-MM-DD`, `-calendar-previous`, `-calendar-next`; range `-apply`, `-cancel`, `-reset`                                                                                                                        |
| Calendar                                                           | Root                                                    | `-day-YYYY-MM-DD`, `-previous`, `-next`, `-monthSelect`, `-yearSelect`                                                                                                                                                                                            |
| DialogContent, DrawerContent, AlertDialogContent                   | Portalled content                                       | `-overlay`; Dialog/Drawer `-close`. Put explicit IDs on caller-owned alert actions.                                                                                                                                                                               |
| PopoverContent, DropdownMenuContent, Tooltip                       | Portalled content                                       | IDs on explicit trigger/menu items; Tooltip `-arrow`                                                                                                                                                                                                              |
| Tabs, TabsList, TabsTrigger, TabsContent; Sidebar parts; templates | Each supplied primitive root                            | Pass IDs on individual triggers/panels/navigation items; inherited native attributes are forwarded.                                                                                                                                                               |
| Avatar                                                             | Avatar root                                             | `-image`, `-fallback`, `-spinner`                                                                                                                                                                                                                                 |
| AvatarUpload                                                       | Field root                                              | `-upload`, `-input` (file picker), `-remove`; crop `-crop-cropDialog`, `-crop-cropSlider`, `-crop-cropApply`, `-crop-cropCancel`                                                                                                                                  |
| UploadField                                                        | Field root                                              | `-input`, `-trigger`, `-dropzone`, `-files-list`; file actions derive from filename/lastModified/index within `-files` scope. Prefer file preview/remove ARIA labels for duplicate filenames.                                                                     |
| Editor                                                             | Field root                                              | `-input` (contenteditable), `-toolbar`, `-command-{iconName}` (e.g. bold, italic, undo), `-error`                                                                                                                                                                 |
| Pagination                                                         | Navigation root                                         | `-first`, `-previous`, `-next`, `-last`, `-page-1`, `-page-2`, … (one-based page numbers)                                                                                                                                                                         |
| DataTable                                                          | Field/container root                                    | `-filter`, `-row-{rowId}`, `-cell-{rowId}-{columnId}`, `-checkbox-{rowId}`, `-sortButton-{columnId}`, `-selectPage-{headerGroupId}`, `-clearSelection`, `-columnsTrigger`, `-columnToggle-{columnId}`, `-retry`, `-emptyState`, `-pageSize`, `-pagination-page-2` |
| Tree                                                               | Tree root                                               | `-item-{nodeId}`, `-toggle-{nodeId}`, `-label-{nodeId}`                                                                                                                                                                                                           |
| ToastProvider                                                      | Viewport wrapper                                        | Message `-toast-{id}` and `-toast-{id}-close`; a message's own `data-testid` overrides its derived ID. Use an explicit toast `id` when tests need stable identity.                                                                                                |
| Form                                                               | Native form                                             | `FormField data-testid` forwards to the bound child; an explicit child's ID wins. Bound field wrappers inherit each control's selector contract. Render-function fields expose `-field`; assign IDs inside the render function.                                   |
| EmptyState, PageHeader, Stepper, WorkspaceShell                    | Native root                                             | Assign IDs to consumer-owned actions/slots.                                                                                                                                                                                                                       |

Dynamic key segments use `encodeURIComponent`: option `a/b` becomes `category-option-a%2Fb`. `partTestId` and `TestIdProps` are exported from UI common for host compositions. IDs follow stable table row/column IDs and option values across sort/page/search; no old data is cached. Hosts must keep IDs unique in their mounted scope. Upload file actions use a local list index for otherwise indistinguishable file entries; they are not durable server file IDs.

```ts
await page.getByTestId('profile-password-toggle').click();
await page.getByTestId('profile-category').getByRole('combobox').fill('Lorem');
await page.getByTestId('profile-category-option-alpha').click();
await page.getByTestId('orders-pagination-page-2').click();
await page.getByTestId('orders-checkbox-item-12').check();
```

Portal menus/dialogs live outside the originating DOM subtree. Query them from page/document, not only from the field wrapper. Prefer `.check()`/`.uncheck()` where supported to make checkbox tests idempotent; retain keyboard/role-based coverage as well.

## Coverage and review

`Foundations/Testing` in Storybook shows controls, portals and stable row selectors. Contract tests verify native targets, unique repeated IDs, no implicit IDs, portalled Select options after reordering, table selection after page changes, calendar days and dialog dismissal controls. Existing upload/crop/form/toast tests also verify selector forwarding. Build Storybook, typecheck and run tests after altering this contract. Browser end-to-end execution is separate; these tests run in jsdom and do not claim browser layout validation.

Chart uses an optional figure base plus viewport/plot/state/retry/legend/table selectors and stable URI-encoded row/series IDs in the equivalent data table; see UI_CHARTS.md. Accordion derives item/header/trigger/icon/content/body selectors from stable item values, with explicit part overrides; see UI_ACCORDION.md. Neither emits default IDs or uses translated labels as identity.

Modal calls accept an optional panel base, deriving existing Dialog/AlertDialog parts and Modal ok/error via partTestId. A provider base optionally derives modal-{encodedId}; explicit per-call selectors win. No IDs appear without a base. Query from document/page and use stable explicit IDs for provider-derived selectors. See [UI_MODAL.md](UI_MODAL.md).
