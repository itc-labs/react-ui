# Templates

Template sắp xếp một trang bằng slot. WorkspaceShell nhận `sidebar`, `header` và `content` (hoặc `children`) và tự tạo cấu trúc body/header/main. Template không có nội dung nghiệp vụ, gọi API, route hay luồng cố định.

```tsx
import { WorkspaceShell } from '@itclabs/react-ui/templates';
import { Sidebar } from '@itclabs/react-ui/modules';
import { Breadcrumb } from '@itclabs/react-ui/components';

<WorkspaceShell
  sidebar={<Sidebar items={navigation} />}
  header={<Breadcrumb items={breadcrumb} />}
  content={children}
/>;
```

Mỗi slot có class qua `classNames` (`root`, `body`, `header`, `main`). Các part `WorkspaceBody`, `WorkspaceHeader`, `WorkspaceMain` vẫn còn cho bố cục tùy biến.

Giữ template nhỏ: chỉ thêm layout khi có cấu trúc lặp lại; không biến một màn hình nghiệp vụ thành component chung với nhiều cờ.
