# Getting started

## 1. Install

Start with a React 19 application that already has `react` and `react-dom` installed, then add the kit:

```bash
pnpm add @itclabs/react-ui
```

pnpm and npm (v7+) install the required peers automatically: `valibot`, `date-fns`, `@date-fns/tz`, `@tanstack/react-form` and `@tanstack/react-table`. Add them to your own `package.json` only if your app imports them directly (for example, Valibot schemas shared with server code) or your package manager does not auto-install peers (Yarn, or pnpm with `auto-install-peers=false`):

```bash
pnpm add valibot date-fns @date-fns/tz @tanstack/react-form @tanstack/react-table
```

Supported peer versions: Valibot 1, date-fns 4, `@date-fns/tz` ^1.2.0, TanStack Form 1, and TanStack Table 8.

Install optional peers only for the features you use:

| Feature entry point               | Optional peers                                                            |
| --------------------------------- | ------------------------------------------------------------------------- |
| `@itclabs/react-ui/editor`        | `@tiptap/react` ^3.0.0, `@tiptap/pm` ^3.0.0, `@tiptap/starter-kit` ^3.0.0 |
| `@itclabs/react-ui/chart`         | `recharts` ^3.0.0, `react-is` ^19.0.0                                     |
| `@itclabs/react-ui/avatar-upload` | `react-easy-crop` ^6.0.0                                                  |

## 2. Load CSS once

Choose **one** stylesheet in your application's global CSS.

For a **Tailwind CSS v4 host**, use the source entry, which includes Tailwind, tokens, fonts, base rules, vendor styles, and motion:

```css
@import '@itclabs/react-ui/theme/styles.css';
```

The theme registers the kit's own class sources, so you do not need an `@source` pointing into `node_modules`. Add `@source` only for your own folders that Tailwind does not detect automatically.

For a **host without Tailwind**, use the precompiled stylesheet:

```css
@import '@itclabs/react-ui/ui.css';
```

The compiled stylesheet supplies kit styles; it does not generate utilities for your own markup. See [Theming](?path=/docs/guides-theming--docs) for individual CSS entries and token overrides.

## 3. Mount the providers

This complete client module uses native link and image adapters. Wrap your screen in `UIRoot` at the application root. Choose `en-US` explicitly because the default locale is `vi-VN`.

```tsx
'use client';

import type { ReactNode } from 'react';
import {
  UIProvider,
  ToastProvider,
  ModalProvider,
  type UiLinkProps,
  type UiImageProps,
} from '@itclabs/react-ui';

function AppLink(props: UiLinkProps) {
  return <a {...props} />;
}

function AppImage(props: UiImageProps) {
  return <img {...props} />;
}

export function UIRoot({ children }: { children: ReactNode }) {
  return (
    <UIProvider locale="en-US" link={AppLink} image={AppImage}>
      <ToastProvider>
        <ModalProvider>{children}</ModalProvider>
      </ToastProvider>
    </UIProvider>
  );
}
```

Native adapters are also the defaults. Replace them with framework adapters when needed; see [Providers & adapters](?path=/docs/guides-providers-adapters--docs).

## 4. Build a first screen

Render `FirstScreen` inside `UIRoot`. Wrap ordinary controls in `FormField` inside `Form`; `schema` holds the Valibot rule for each field, and a `Button type="submit"` shows loading while the form submits. Saving here is a local demonstration that shows a toast; connect your own persistence in `onSubmit`.

```tsx
'use client';

import * as v from 'valibot';
import { Button, Form, FormField, Input, toast, useAppForm } from '@itclabs/react-ui';

const schema = {
  name: v.pipe(v.string(), v.trim(), v.minLength(1, 'Enter a name.')),
};

export function FirstScreen() {
  const form = useAppForm({
    defaultValues: { name: '' },
    onSubmit: async () => {
      toast.success('Demo saved.');
    },
  });

  return (
    <main className="grid max-w-md gap-4">
      <h1>Lorem ipsum</h1>
      <Form form={form} schema={schema} aria-label="Profile" className="grid gap-4">
        <FormField name="name" label="Name" required>
          <Input placeholder="Lorem ipsum" />
        </FormField>
        <Button type="submit">Save</Button>
      </Form>
    </main>
  );
}
```
