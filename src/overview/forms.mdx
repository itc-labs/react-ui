# Forms

`useAppForm` creates the TanStack Form state. The recommended pattern, used throughout the Form stories, wraps ordinary kit controls in `FormField` inside `Form`, passes per-field Valibot rules through `Form schema` and submits with a plain `Button type="submit"`, which shows loading and stays disabled while the form submits. `form.AppField` bound fields are a shorter alternative. `Form` supplies context, prevents native submission, and focuses the first element marked `aria-invalid="true"` after submission completes.

## Compose controls with FormField (recommended)

`FormField name` uses the surrounding `Form` context. Alternatively, pass `field` from a field render callback. Native inputs and event-based kit inputs use `onChange`; kit value controls such as `Select` and `NumberInput` automatically use `onValueChange`. Boolean values use checked binding. The wrapper also connects blur, labels, and errors.

`NumberInput` and `NumberField` use `number | null`: `null` means empty, while `0` is a real value. Preserve that distinction in defaults, validation, and payloads. Do not replace an empty value with zero using a truthiness fallback. NumberInput displays dot thousands separators and a comma decimal separator; form state remains numeric.

```tsx
import { useState } from 'react';
import * as v from 'valibot';
import {
  Button,
  Checkbox,
  Form,
  FormField,
  Input,
  NumberInput,
  Select,
  useAppForm,
} from '@itclabs/react-ui';

export function ItemForm({
  save,
}: {
  save: (value: {
    title: string;
    quantity: number | null;
    status: string;
    enabled: boolean;
  }) => Promise<void>;
}) {
  const [error, setError] = useState('');
  const form = useAppForm({
    defaultValues: {
      title: '',
      quantity: null as number | null,
      status: 'draft',
      enabled: false,
    },
    onSubmit: async ({ value }) => {
      setError('');
      try {
        await save(value);
      } catch {
        setError('Could not save. Try again.');
      }
    },
  });

  return (
    <Form
      form={form}
      schema={{
        title: v.pipe(v.string(), v.minLength(1, 'Enter a title.')),
        quantity: v.pipe(
          v.number('Enter a quantity.'),
          v.minValue(0, 'Use zero or more.'),
        ),
      }}
    >
      <FormField name="title" label="Title" required>
        <Input />
      </FormField>
      <FormField name="quantity" label="Quantity" required>
        <NumberInput min={0} />
      </FormField>
      <FormField name="status" label="Status">
        <Select
          options={[
            { value: 'draft', label: 'Draft' },
            { value: 'published', label: 'Published' },
          ]}
        />
      </FormField>
      <FormField name="enabled">
        <Checkbox label="Enable item" />
      </FormField>
      <Button type="submit">Save item</Button>
      {error && <p role="alert">{error}</p>}
    </Form>
  );
}
```

Return or await the save promise inside `onSubmit` so submitting state covers the entire operation. `form.SubmitButton` sets `type="submit"`, shows loading state, and disables submission when `canSubmit` is false. A `Button type="submit"` inside `Form` shows the same loading state automatically; pass `loading` to control it yourself. Use `FormSubmit`, which exposes `(isSubmitting, canSubmit)`, when the button also depends on `canSubmit` or lives outside `Form` (`form={form}`).

Keep validation errors next to controls; use persistent feedback for submission failures. See [Overlays & feedback](?path=/docs/guides-overlays-feedback--docs) for optional success notifications.

## Rating with FormField

`Rating` binds automatically through `value` and `onValueChange`. Use zero for an unselected score and `allowHalf` for half-point choices. `allowClear` lets users select the current score again to reset it to zero; validate a positive minimum when a score is required. Arrow keys choose adjacent scores, while Home and End choose the first and last choices. For display only, use `readOnly` with `value` outside the form.

```tsx
import * as v from 'valibot';
import { Button, Form, FormField, Rating, useAppForm } from '@itclabs/react-ui';

export function ScoreForm({
  save,
}: {
  save: (value: { score: number }) => Promise<void>;
}) {
  const form = useAppForm({
    defaultValues: { score: 0 },
    onSubmit: async ({ value }) => {
      await save(value);
    },
  });

  return (
    <Form
      form={form}
      schema={{
        score: v.pipe(v.number(), v.minValue(0.5, 'Select a score.')),
      }}
    >
      <FormField name="score" label="Score" required>
        <Rating max={5} allowHalf allowClear showValue />
      </FormField>
      <Button type="submit">Save score</Button>
    </Form>
  );
}
```

See [Rating stories](?path=/docs/components-rating--docs) for sizes, display mode, and custom glyphs.

## Variant selector with OptionGroup, QuantityInput, and ColorPicker

All three controls bind automatically through `value` and `onValueChange` inside `FormField`. `OptionGroup` stores a string option value: use `variant="swatch"` with `color` or `image` options, or the default chips for sizes. Disabled options remain visible but cannot be selected. Arrow keys cycle through available visible options; Home and End select the first and last. `maxVisible` adds an expansion button while keeping the selected option visible.

`QuantityInput` stores a number and normalizes edits to `min`, `max`, and a step grid anchored at `min`. Arrow Up/Down steps once; Page Up/Down steps ten times. Empty edits restore the previous quantity on blur. `ColorPicker` stores a hex string; `alpha` enables eight-digit hex values. Hex edits commit on Enter or blur, and invalid edits leave the selection intact. Presets are optional; screen sampling appears only where the browser supports it. Escape closes the picker and restores trigger focus.

```tsx
import * as v from 'valibot';
import {
  Button,
  ColorPicker,
  Form,
  FormField,
  OptionGroup,
  QuantityInput,
  useAppForm,
} from '@itclabs/react-ui';

type VariantSelection = {
  color: string;
  size: string;
  quantity: number;
  customColor: string;
};

export function VariantForm({
  save,
}: {
  save: (selection: VariantSelection) => Promise<void>;
}) {
  const form = useAppForm({
    defaultValues: {
      color: 'blue',
      size: 'M',
      quantity: 1,
      customColor: '#336699',
    },
    onSubmit: async ({ value }) => {
      await save(value);
    },
  });

  return (
    <Form
      form={form}
      className="grid max-w-md gap-6"
      schema={{
        color: v.picklist(['blue', 'pink'], 'Choose an available color.'),
        size: v.picklist(['S', 'M', 'L'], 'Choose an available size.'),
        quantity: v.pipe(v.number(), v.integer(), v.minValue(1), v.maxValue(10)),
        customColor: v.pipe(
          v.string(),
          v.regex(/^#[0-9a-f]{6}$/i, 'Choose a hex color.'),
        ),
      }}
    >
      <FormField name="color" label="Color" required>
        <OptionGroup
          variant="swatch"
          options={[
            { value: 'blue', label: 'Blue', color: '#336699' },
            { value: 'pink', label: 'Pink', color: '#cc6699' },
            { value: 'green', label: 'Green', color: '#669933', disabled: true },
          ]}
        />
      </FormField>
      <FormField name="size" label="Size" required>
        <OptionGroup
          options={[
            { value: 'S', label: 'S' },
            { value: 'M', label: 'M' },
            { value: 'L', label: 'L' },
          ]}
        />
      </FormField>
      <FormField name="quantity" label="Quantity" required>
        <QuantityInput min={1} max={10} step={1} />
      </FormField>
      <FormField name="customColor" label="Custom color" required>
        <ColorPicker presets={['#336699', '#cc6699', '#669933']} />
      </FormField>
      <Button type="submit">Save variant</Button>
    </Form>
  );
}
```

See [OptionGroup](?path=/docs/components-optiongroup--docs), [QuantityInput](?path=/docs/components-quantityinput--docs), and [ColorPicker](?path=/docs/components-colorpicker--docs) for focused examples and customization slots.

## Bound fields (alternative)

As an alternative for simple forms, render bound controls inside `form.AppField`. Each field handles its value, blur state, and error message. Available fields include text, textarea, password, number, OTP, select, multi-select, checkbox, switch, radio group, date, time, date range, and upload. Editor and avatar fields have separate module entry points; see the [catalog](?path=/docs/reference-catalog--docs).

Keep Valibot rules in a shared module without browser dependencies. Export both the field map for `Form schema` and an object schema for parsing the submitted payload on the server. Client validation improves feedback; the server must validate incoming data again. `required` adds the control's required semantics and indicator; encode validation rules in the schema.

```tsx
import { useState } from 'react';
import * as v from 'valibot';
import { Form, useAppForm } from '@itclabs/react-ui';

// These exports can live in a shared schema module imported by client and server.
export const profileFields = {
  name: v.pipe(v.string(), v.trim(), v.minLength(1, 'Enter a name.')),
  email: v.pipe(v.string(), v.email('Enter a valid email address.')),
};
export const profileSchema = v.object(profileFields);

export function parseProfileOnServer(payload: unknown) {
  return v.parse(profileSchema, payload);
}

export function ProfileForm({
  save,
}: {
  save: (profile: v.InferOutput<typeof profileSchema>) => Promise<void>;
}) {
  const [status, setStatus] = useState('');
  const form = useAppForm({
    defaultValues: { name: '', email: '' },
    validators: { onChange: profileSchema },
    onSubmit: async ({ value }) => {
      setStatus('');
      try {
        await save(v.parse(profileSchema, value));
        setStatus('Saved.');
      } catch {
        setStatus('Could not save. Try again.');
      }
    },
  });

  return (
    <Form form={form} aria-label="Profile">
      <form.AppField name="name">
        {(field) => <field.TextField label="Name" required />}
      </form.AppField>
      <form.AppField name="email">
        {(field) => <field.TextField label="Email" type="email" required />}
      </form.AppField>
      <form.SubmitButton>Save profile</form.SubmitButton>
      <p role="status">{status}</p>
    </Form>
  );
}
```

`Form schema` installs per-field `onChange` validators for `FormField name`, which also run on submit. Bound `form.AppField` controls use validators passed to `useAppForm` or to the field itself, as in the example above. For whole-form or cross-field validation, use TanStack Form's `validators` option on `useAppForm`. Schema parsing can transform values, so use the parsed output when saving.

## Custom wrappers

An opaque wrapper does not inherit a kit control's auto-binding marker. Set `binding="value"` for `value`/`onValueChange`, `binding="checked"` for `checked`/`onCheckedChange`, or `binding="native"` for event-based `onChange`. Use `mapValue` and `mapOnChange` when display and stored values differ. `mapOnChange` receives the extracted value, after native event handling.

Forward the injected ID, name, blur handler, label, error, and ref to the actual control so accessibility and error focus keep working. For other callback shapes, use a `FormField` render function and bind the field manually.

```tsx
import * as v from 'valibot';
import {
  Form,
  FormField,
  NumberInput,
  useAppForm,
  type NumberInputProps,
} from '@itclabs/react-ui';

function PercentageInput(props: NumberInputProps) {
  return <NumberInput {...props} min={0} max={100} />;
}

export function RateForm({ save }: { save: (rate: number | null) => Promise<void> }) {
  const form = useAppForm({
    defaultValues: { rate: null as number | null },
    onSubmit: async ({ value }) => {
      await save(value.rate);
    },
  });

  return (
    <Form
      form={form}
      schema={{ rate: v.nullable(v.pipe(v.number(), v.minValue(0), v.maxValue(1))) }}
    >
      <FormField
        name="rate"
        label="Rate (%)"
        binding="value"
        mapValue={(value) => (typeof value === 'number' ? value * 100 : null)}
        mapOnChange={(value) => (typeof value === 'number' ? value / 100 : null)}
      >
        <PercentageInput />
      </FormField>
      <form.SubmitButton>Save rate</form.SubmitButton>
    </Form>
  );
}
```
