# Toast

Dùng **toast.error / toast.info / toast.warning / toast.success** trong event handler, async function hoặc module browser thông thường. Không cần gọi hook trong function đó.

<Canvas of={Toasts.PureFunction} />

<Source language="tsx" code={`import { toast } from '@itclabs/react-ui/toast';

export function reportError() {
  toast.error('Không thể lưu', { description: 'Vui lòng thử lại.' });
}

export function reportSuccess() {
  toast.success('Đã lưu');
}
`} />

Đặt ToastProvider một lần ở gốc ứng dụng trước khi gọi toast.

<Source language="tsx" code={`import type { ReactNode } from 'react';
import { ToastProvider } from '@itclabs/react-ui';

export function App({ children }: { children: ReactNode }) {
  return <ToastProvider>{children}</ToastProvider>;
}
`} />

## Queue

Các toast vượt giới hạn sẽ chờ đến lượt; đóng một toast để xem toast tiếp theo. clearQueue xóa hàng chờ, dismiss đóng theo ID hoặc toàn bộ scope.

## Scope riêng

useToast vẫn có cho scope riêng; nó trả về cùng bộ methods. Với nhiều app chạy trên cùng trang, tạo client riêng bằng createToastClient rồi truyền qua ToastProvider client. Các demo phụ dùng client=null để giữ scope độc lập; cách dùng thông thường chỉ cần provider mặc định một lần. Không gọi notification browser từ server action.

Dùng locale và classNames trên UIProvider/ToastProvider để đồng bộ ngôn ngữ và giao diện.
