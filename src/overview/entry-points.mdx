# Entry points & bundle size

## Package exports

Append each subpath to `@itclabs/react-ui`; `.` means the package root. Wildcards select individual modules without a file extension. The source and published package expose the same subpaths.

| Subpath                            | Contents                                                                                                                                                                            |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.`                                | Root API: components, modules, templates, theme, locale helpers, hooks, and shared utilities; excludes editor, chart, avatar upload, CodeView, Carousel, and MediaGallery/Lightbox. |
| `./components`                     | Primitive components, including OptionGroup, QuantityInput, ColorPicker, Rating, and JsonView, providers, and shared component utilities.                                           |
| `./modules`                        | Composed UI modules, navigation helpers, and the event calendar as `EventCalendar`.                                                                                                 |
| `./theme/tokens.css`               | Tailwind v4 theme tokens and semantic CSS variables.                                                                                                                                |
| `./theme/custom-theme.example.css` | Example CSS token overrides to copy and adapt.                                                                                                                                      |
| `./templates`                      | `WorkspaceShell`, `WorkspaceBody`, `WorkspaceHeader`, and `WorkspaceMain`.                                                                                                          |
| `./theme`                          | Theme definitions, token names, colors, icon pack helpers, and types.                                                                                                               |
| `./theme/provider`                 | `UIProvider` and `useTheme` for React integration.                                                                                                                                  |
| `./i18n`                           | Locale definitions, built-in English and Vietnamese locales, and translation helpers.                                                                                               |
| `./i18n/react`                     | `UILocaleProvider` and `useUILocale` for React locale integration.                                                                                                                  |
| `./hooks`                          | `useDebounce`, `useDebouncedCallback`, and `useClickOutside`.                                                                                                                       |
| `./icons/custom`                   | Custom sorting glyphs and spinner glyph.                                                                                                                                            |
| `./illustrations`                  | `Illustration`, its props, and the supported illustration names.                                                                                                                    |
| `./illustrations/*`                | Individual illustration modules, such as `/illustrations/empty`.                                                                                                                    |
| `./icons/outline`                  | Named outline glyph exports.                                                                                                                                                        |
| `./icons/outline/*`                | Individual outline glyph modules, such as `/icons/outline/search`.                                                                                                                  |
| `./icons/bold`                     | Named bold glyph exports.                                                                                                                                                           |
| `./icons/bold/*`                   | Individual bold glyph modules, such as `/icons/bold/search`.                                                                                                                        |
| `./icons/catalog`                  | Icon inventory metadata for discovery and tooling.                                                                                                                                  |
| `./modal`                          | Hook-free `modal` facade, `createModalClient`, and client types; requires a mounted `ModalProvider` to call.                                                                        |
| `./toast`                          | Hook-free `toast` facade, `createToastClient`, and client types; requires a mounted `ToastProvider` to call.                                                                        |
| `./theme/styles.css`               | Tailwind source stylesheet combining tokens, fonts, base rules, vendor styles, and motion.                                                                                          |
| `./theme/fonts.css`                | Be Vietnam Pro font faces at weights 400, 500, 600, and 700.                                                                                                                        |
| `./theme/base.css`                 | Base body and interaction cursor styles.                                                                                                                                            |
| `./theme/vendor.css`               | Toast, crop, editor, and event calendar styles.                                                                                                                                     |
| `./theme/motion.css`               | Overlay, toast, submenu, and badge animations with reduced-motion support.                                                                                                          |
| `./theme/fonts-800.css`            | Optional Be Vietnam Pro font faces at weight 800.                                                                                                                                   |
| `./editor`                         | Optional Tiptap `Editor` and `EditorField` integration.                                                                                                                             |
| `./chart`                          | Optional Recharts `Chart`, data types, and styling types.                                                                                                                           |
| `./avatar-upload`                  | Optional `AvatarUpload` and `AvatarField` integration with cropping.                                                                                                                |
| `./ui.css`                         | Compiled CSS for consumers without a Tailwind build.                                                                                                                                |
| `./navigation`                     | Router-independent `matchPath`, `resolveActiveNav`, `filterNavByAccess`, and navigation types.                                                                                      |
| `./carousel`                       | Responsive `Carousel` and types; Embla is isolated from the root and barrels.                                                                                                       |
| `./media-gallery`                  | `MediaGallery`, `Lightbox`, `MediaItem`, and types; image/video browsing, fullscreen viewing, zoom, and responsive thumbnails. Excluded from all barrels.                           |
| `./calendar`                       | Event `Calendar`, its engine helpers, and types.                                                                                                                                    |
| `./code-view`                      | Read-only `CodeView` and its types; Prism is loaded only through this subpath.                                                                                                      |

See [Getting started](?path=/docs/overview-getting-started--docs) for CSS setup and [Providers & adapters](?path=/docs/guides-providers-adapters--docs) for provider wiring.

## Measured bundle size

Measured on October 30, 2026 by running:

```bash
node scripts/measure-icon-bundles.mjs
```

The script bundles source entries with esbuild for the browser as minified production ESM, then compresses them with Node gzip. React, React DOM, and their subpaths are external; CSS is excluded. Other runtime dependencies are bundled. Values below use decimal KB (1 KB = 1,000 bytes) and represent each entry independently; do not add them together.

| OptionGroup                 |   41.02 |
| JsonView                    |   19.71 |
| CodeView                    |   45.81 |
| Button                      |   17.82 |
| Spinner                     |   17.02 |
| Dialog                      |   34.75 |

These are script fixtures, not predictions for a complete application. The root fixture retains all root exports; the other fixtures retain the named exports shown. Application imports and bundler settings can produce different results.

Gzip budgets are enforced by `src/components/icon/bundle-size.test.ts`, which runs the same script and checks the complete measurement key list. The script guards against full icon packs in ordinary imports; the built-in icon registry in Button, Dialog, Rating, QuantityInput, ColorPicker, OptionGroup, JsonView, CodeView, Carousel, MediaGallery, and Lightbox; React Select in DataTable and Calendar; optional heavy features in Calendar; and MediaGallery, Prism, and Embla in the root entry.

| ColorPicker   |              54,300 |
| MediaGallery  |              54,800 |

CodeView retains its 50,000-byte budget and Carousel its 30,300-byte budget. Root measures 261,152 bytes against its existing 270,000-byte budget, leaving 8,848 bytes of headroom; no increase is needed.

## Tree-shaking tips

- Use named imports and keep ESM intact so the application bundler can remove unused exports. JavaScript modules are declared side-effect free; CSS is preserved as a side effect.
- Import individual glyphs, such as `@itclabs/react-ui/icons/outline/search`, for explicit icon dependencies. Avoid importing `/icons/outline/pack` or `/icons/bold/pack` unless you need every icon in that runtime pack.
- Import `CodeView` from `/code-view`, `Carousel` from `/carousel`, and `MediaGallery`/`Lightbox` from `/media-gallery`; these are excluded from the root, `/components`, and `/modules` barrels. OptionGroup, QuantityInput, ColorPicker, Rating, and JsonView are available from the root and `/components`. See [Data display](?path=/docs/guides-data-display--docs) for examples.
- Import optional features from `/editor`, `/chart`, or `/avatar-upload` only where needed. They are excluded from the root and `/modules` barrels.
- Use `/modal` and `/toast` for imperative calls outside React components; mount their providers in the React tree.
- Load `/icons/catalog` only for icon discovery or tooling. Import individual `/illustrations/*` modules when a single illustration is enough.

See [Icons](?path=/docs/guides-icons--docs), [Theming](?path=/docs/guides-theming--docs), and [Catalog](?path=/docs/reference-catalog--docs) for related guidance.
