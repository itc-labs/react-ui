# Entry points & bundle size

Append each subpath to `@itclabs/react-ui`; `.` means the package root. Wildcards select individual modules without a file extension. The source and published package expose the same subpaths.

## Tree-shaking tips

- Use named imports and keep ESM intact so the application bundler can remove unused exports. JavaScript modules are declared side-effect free; CSS is preserved as a side effect.
- Import individual glyphs, such as `@itclabs/react-ui/icons/outline/search`, for explicit icon dependencies. Avoid importing `/icons/outline/pack` or `/icons/bold/pack` unless you need every icon in that runtime pack.
- Import `TreeSelect` from `/tree-select`, `Transfer` from `/transfer`, and `RichTextView` from `/rich-text-view`; these are isolated from the root and both component/module barrels. Divider, Kbd, Timeline, and Slider are core exports.
- Import `CodeView` from `/code-view`, `Carousel` from `/carousel`, and `MediaGallery`/`Lightbox` from `/media-gallery`; these are excluded from the root, `/components`, and `/modules` barrels. OptionGroup, QuantityInput, ColorPicker, Rating, and JsonView are available from the root and `/components`. See [Data display](?path=/docs/guides-data-display--docs) for examples.
- Import optional features from `/editor`, `/chart`, or `/avatar-upload` only where needed. They are excluded from the root and `/modules` barrels.
- Use `/modal` and `/toast` for imperative calls outside React components; mount their providers in the React tree.
- Load `/icons/catalog` only for icon discovery or tooling. Import individual `/illustrations/*` modules when a single illustration is enough.

See [Icons](?path=/docs/guides-icons--docs), [Theming](?path=/docs/guides-theming--docs), and [Catalog](?path=/docs/reference-catalog--docs) for related guidance.

## Drag and drop

Import primitives from `@itclabs/react-ui/dnd`. IDs must be stable, non-empty, and globally unique across a board. `items` and `containers` are controlled: apply `onReorder` or `onMove` results to persist a drop. Cancellation never changes the data. Callbacks include zero-based indices. Cross-container moves insert before the target item; empty containers insert at zero. `canDrop` applies to keyboard and pointer targets and is checked again on drop.

Set `handle` and spread `renderItem` state’s `handleProps` onto `DragHandle` for handle-only dragging. `getLabel` supplies readable announcement names; IDs are the fallback. `renderContainer(container, children)` must retain its supplied drop zone. `gap` uses kit spacing steps (0, 1, 2, 3, 4, 6, 8); `orientation` selects vertical, horizontal, or grid sorting. Root native props, React 19 refs, typed class slots, and derived part test IDs are supported. `restrictToParent` and `lockAxis` configure dnd-kit modifiers.

`DndProvider` accepts DndContext options, with a 4px Pointer sensor activation distance, Keyboard sensor with sortable coordinates, auto-scroll, and English/Vietnamese announcements and instructions. Space/Enter picks up and drops, arrows move, and Escape cancels. Compositions restore focus to the moved activator, and reduced motion disables sorting transitions and drop animation. `useSortableItem` exposes dnd-kit’s sortable hook for custom compositions; advanced consumers own their SortableContext and overlay. The full dnd entry measures 36,875 bytes gzip (40,600-byte budget), including dnd-kit and shared localization. These ordering compositions are not value-style form controls.
