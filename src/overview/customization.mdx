# Customization

Use `className` for the component's primary element and typed `classNames` slots for its parts. Use [Theming](?path=/docs/guides-theming--docs) for shared design tokens and [Icons](?path=/docs/guides-icons--docs) for icon packs. A single control does not need a new theme.

## Merge order and cn()

Components merge default and state classes first, then your slot classes, then `className` on the same element. The last conflicting utility wins through `cn()`, which combines `clsx` with Tailwind merging, including the kit's semantic typography, spacing, radius, and shadow utilities. This utility merging does not replace the CSS cascade for arbitrary custom classes.

The element receiving `className` varies by component. For `Input`, it is the native input; `classNames.root` styles the field wrapper. `rootClassName`, where supported, comes after the root slot.

```tsx
import { cn, Input } from '@itclabs/react-ui';

export function Example() {
  return (
    <Input
      label="Display name"
      hint="Enter the name shown on your profile."
      classNames={{
        root: 'max-w-sm gap-2',
        label: 'text-brand-700',
        control: 'rounded-full',
        hint: 'text-ui-sm',
      }}
      className={cn('px-4', 'px-6')}
    />
  );
}
```

Here `px-6` wins over `px-4`; the control slot replaces the default radius. Your application must provide CSS for its classes. With Tailwind, ensure your application's source files are scanned.

## Select slots

Select exposes label, control, menu, option, and other React Select slots. React Select slot values accept strings or callbacks with state such as `isFocused`, `isSelected`, and `isDisabled`. `className` targets the React Select container; `classNames.root` targets the outer field wrapper.

```tsx
import { cn, Select } from '@itclabs/react-ui';

export function Example() {
  return (
    <Select
      label="Status"
      options={[
        { value: 'draft', label: 'Draft' },
        { value: 'published', label: 'Published' },
      ]}
      classNames={{
        root: 'max-w-sm',
        control: 'rounded-full',
        option: ({ isSelected }) => cn(isSelected && 'font-semibold'),
      }}
    />
  );
}
```

## Compound components and portals

Tabs, Breadcrumb, Sidebar, and Dialog parts accept their own `className`. `DialogContent` and `DrawerContent` also expose `classNames.overlay` and `classNames.close` for the parts they render internally. Menu and Popover retain Radix portals and semantics. See [Overlays & feedback](?path=/docs/guides-overlays-feedback--docs).

Other controls include a **CustomClasses** story in their component group. Single-element components such as Icon and Skeleton use `className`. Headless roots that render no DOM do not gain wrappers or styling props.

## Test selectors

Pass a consumer-owned `data-testid` to opt into test selectors. Components use `partTestId(base, part, ...keys)` for generated parts. It returns `undefined` when the base is absent; otherwise it joins the base, part, and URL-encoded keys with hyphens. It encodes keys with `encodeURIComponent(String(key))`.

```tsx
import { Input, partTestId } from '@itclabs/react-ui';

export const fieldSelectors = {
  control: 'profile-name',
  root: partTestId('profile-name', 'root'),
  label: partTestId('profile-name', 'label'),
  hint: partTestId('profile-name', 'hint'),
};

export const rowSelector = partTestId('records', 'row', 'a/b');
// rowSelector is "records-row-a%2Fb".

export function Example() {
  return (
    <Input
      data-testid={fieldSelectors.control}
      label="Display name"
      hint="Enter the name shown on your profile."
    />
  );
}
```

For this Input, the base ID targets the native input; the wrapper, label, and hint receive the derived IDs shown above. Parts rendered conditionally only receive selectors when present. Other components define their own parts and key structure; inspect their API or source before selecting them. Test IDs do not replace accessible labels or change styling and behavior.
