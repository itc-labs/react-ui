## Templates

Workspace structure and complete layout examples. WorkspaceShell is exported by the package; ApplicationLayout and CalendarPage are story compositions to adapt in your application.

### Workspace layouts

| Name              | Purpose                                                                 | Story docs                                                |
| ----------------- | ----------------------------------------------------------------------- | --------------------------------------------------------- |
| WorkspaceShell    | Arrange sidebar, header, and main content slots.                        | [Examples](?path=/docs/templates-workspaceshell--docs)    |
| ApplicationLayout | Demonstrate sidebar or top navigation with a user menu and page header. | [Examples](?path=/docs/templates-applicationlayout--docs) |
| CalendarPage      | Demonstrate an event calendar within a workspace layout.                | [Examples](?path=/docs/templates-calendarpage--docs)      |

The component Calendar selects dates. The module Calendar manages events and is exported as `EventCalendar` from the root and `/modules`, or as `Calendar` from `/calendar`. See [Event calendar](?path=/docs/guides-event-calendar--docs).

For implementation guidance, see [Data display](?path=/docs/guides-data-display--docs), [Forms](?path=/docs/guides-forms--docs), [Navigation](?path=/docs/guides-navigation--docs), and [Overlays & feedback](?path=/docs/guides-overlays-feedback--docs).
