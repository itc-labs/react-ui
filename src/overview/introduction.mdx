# @itclabs/react-ui

An MIT-licensed React 19 UI kit with Tailwind CSS v4 tokens, accessible controls, composed modules, and page layouts.

## Three layers

| Layer      | Purpose                                          | Examples                      |
| ---------- | ------------------------------------------------ | ----------------------------- |
| Components | Individual controls and feedback                 | Button, Input, Select, Dialog |
| Modules    | Controls composed into reusable interface blocks | Form, DataTable, Sidebar      |
| Templates  | Page layouts with slots for application content  | WorkspaceShell                |

Browse all three in the [Catalog](?path=/docs/reference-catalog--docs).

The host application owns routing, data fetching, authentication, credentials, business rules, and complete screens. Pass data, callbacks, and content into the kit.

## Toolbar tools

- **Theme**: compare Default, Ocean (brand colors), and Compact (shape and font) to check how components respond to host styling.
- **Viewport**: inspect layouts at 390, 768, 1024, and 1440 pixels. Use Tab to check keyboard focus in each layout.
