# Drag & drop

Import the sortable wrappers and integration factories from `@itclabs/react-ui/dnd`.
Wrap your own markup: `Sortable` is the container, `SortableItem` wraps each entry,
`SortableHandle` limits dragging to a grip, and `SortableGroup` connects several
containers. Transfer and DataTable opt in through plugins.
Ordinary root, Transfer and DataTable imports stay independent of dnd-kit.
All examples keep ordering in host state; persist successful changes in your application.

## Accessibility and interaction

Use stable item IDs, unique across a whole group, and give `SortableItem` a readable
`label` for announcements and the handle name. Without a `SortableHandle`, the whole
item is the activator. Keep visible focus indicators and avoid nesting interactive
controls inside a whole-item activator; add a handle when items contain links or buttons.

Tab to an activator. Space or Enter picks up and drops; arrow keys move; Escape
cancels. Transfer also uses Left/Right to change panel, and its reorder integration
and DataTable support Home/End. Focus returns to the moved activator. Announcements
and instructions follow UIProvider's English/Vietnamese locale. Reduced motion
disables sorting transitions and drop animation. Pointer activation requires 4px
of movement; auto-scroll and inert drag overlays are provided.

While dragging, the original slot stays visible as a dashed brand placeholder.
In a group the item is previewed in the container under the pointer, so the
placeholder always marks where the drop lands; `onValueChange` still fires only on
drop. A container that `canDrop` refuses returns the item to its origin while hovered.
The preview is a copy of the item rendered on `document.body`, so transformed
ancestors such as an animating Dialog do not offset it; `SortableOverlay` replaces it.
Transfer and DataTable keep rows in place and draw a brand line before or after
the target row, tint the panel that will receive the item, and show a compact
label chip under the cursor. Keyboard dragging uses the same line.

`DndProvider` supplies sensors and announcements for advanced compositions and
accepts DndContext options. `useSortableItem` exposes the sortable hook. Custom
compositions own their sortable contexts, item bindings, drop zones and overlays.
Sortable, SortableGroup and the plugins already provide their own context.

## Sortable list

`Sortable` owns an ordered ID array through `value` and `onValueChange(next, event)`;
the event reports `activeId`, `overId`, `from` and `to`. Render one `SortableItem` per
ID as a direct child (an array from `map` is fine). `orientation` supports `vertical`,
`horizontal` and `grid`; `lockAxis` and `restrictToParent` constrain movement, and
`gap` uses kit spacing steps. `asChild` on `Sortable` or `SortableItem` merges the
behavior into your own element, such as a `ul` and its `li` rows. An item's children
may be a function receiving `{ isDragging, isOverlay }`.

```tsx
'use client';

import { useState } from 'react';
import { Sortable, SortableHandle, SortableItem } from '@itclabs/react-ui/dnd';

type Item = { id: string; label: string };
const items: Item[] = [
  { id: 'first', label: 'Lorem ipsum' },
  { id: 'second', label: 'Dolor sit amet' },
];

export function ReorderList() {
  const [order, setOrder] = useState(items.map((item) => item.id));

  return (
    <Sortable
      aria-label="Reorder items"
      value={order}
      onValueChange={setOrder}
      lockAxis="y"
    >
      {order.map((id) => {
        const item = items.find((entry) => entry.id === id)!;

        return (
          <SortableItem
            key={id}
            id={id}
            label={item.label}
            className="flex items-center gap-3 rounded-control border border-line bg-surface p-4"
          >
            <SortableHandle />
            <span>{item.label}</span>
          </SortableItem>
        );
      })}
    </Sortable>
  );
}
```

See [Dnd stories](?path=/docs/modules-dnd--docs) for horizontal, grid and `asChild`
layouts and typed `classNames` targets for items, placeholders and overlays.

## Sortable group

`SortableGroup` owns a record of ID arrays keyed by each nested `Sortable` `id`, and
`onValueChange(next, event)` adds `fromContainer` and `toContainer` to the event.
Optional `canDrop(id, from, to)` restricts destinations. The group renders no element,
so place columns in any layout; an empty container shows `emptyContent`.

```tsx
'use client';

import { useState } from 'react';
import {
  Sortable,
  SortableGroup,
  SortableHandle,
  SortableItem,
} from '@itclabs/react-ui/dnd';

const titles: Record<string, string> = { todo: 'To do', done: 'Done' };

export function ReorderBoard() {
  const [columns, setColumns] = useState<Record<string, string[]>>({
    todo: ['Lorem ipsum', 'Dolor sit amet'],
    done: [],
  });

  return (
    <SortableGroup value={columns} onValueChange={setColumns}>
      <div className="grid gap-4 md:grid-cols-2">
        {Object.keys(columns).map((column) => (
          <section key={column} className="grid content-start gap-3">
            <h3>{titles[column]}</h3>
            <Sortable id={column} aria-label={titles[column]}>
              {columns[column]!.map((id) => (
                <SortableItem key={id} id={id} className="flex items-center gap-2 p-2">
                  <SortableHandle />
                  {id}
                </SortableItem>
              ))}
            </Sortable>
          </section>
        ))}
      </div>
    </SortableGroup>
  );
}
```

## Transfer plugin

Inject `createTransferDnd()` to move between panels and reorder selected items.
Dragging implies `order="selection"`: target order follows the value array.
Dragging a checked row moves the checked, enabled rows on that side together.
Search preserves underlying value order. `disabled`, item `disabled`, `maxSelected`
and `oneWay` still constrain moves. Virtualized rows retain an overlay during
scrolling, and keyboard navigation can reach unmounted rows.

```tsx
'use client';

import { useState } from 'react';
import { Transfer, type TransferItem } from '@itclabs/react-ui/transfer';
import { createTransferDnd } from '@itclabs/react-ui/dnd';

const dnd = createTransferDnd();
const items: TransferItem[] = [
  { id: 'first', label: 'Lorem ipsum' },
  { id: 'second', label: 'Dolor sit amet' },
  { id: 'third', label: 'Consectetur adipiscing', disabled: true },
];

export function TransferItems() {
  const [value, setValue] = useState<string[]>(['second']);

  return (
    <Transfer
      label="Items"
      items={items}
      value={value}
      onValueChange={setValue}
      dnd={dnd}
      searchable
    />
  );
}
```

Transfer also supports `defaultValue` and automatic `FormField` binding.
See [Transfer drag and drop](?path=/story/modules-transfer--drag-and-drop).

## DataTable row reorder plugin

Inject `createRowReorder()` through `rowReorder.plugin`. Supply stable `rowId`
values and apply the ordered IDs in `onReorder`. The callback includes every
supplied ID and `{ id, from, to }` with zero-based positions in the supplied rows.
Client filtering and pagination reorder the visible view while preserving all
other IDs. Sorting blocks reorder with a localized explanation. Server mode,
including server pages/groups, also blocks it unless `allowServerReorder: true`;
the host then owns persistence across pages and groups. Loading and `disabled`
block interactions. `handle` defaults to true; false makes the row the activator.
Pass `getLabel` to name rows in the drag chip and announcements; it defaults to the row ID.

```tsx
'use client';

import { useState } from 'react';
import { DataTable, type ColumnDef } from '@itclabs/react-ui';
import { createRowReorder } from '@itclabs/react-ui/dnd';

type Row = { id: string; label: string };
const plugin = createRowReorder();
const columns: ColumnDef<Row, unknown>[] = [{ accessorKey: 'label', header: 'Name' }];

export function ReorderRows() {
  const [rows, setRows] = useState<Row[]>([
    { id: 'first', label: 'Lorem ipsum' },
    { id: 'second', label: 'Dolor sit amet' },
  ]);

  return (
    <DataTable
      caption="Reorder rows"
      rows={rows}
      rowId={(row) => row.id}
      columns={columns}
      rowReorder={{
        plugin,
        getLabel: (row) => row.label,
        onReorder: (ids) =>
          setRows(ids.map((id) => rows.find((row) => row.id === id)!)),
      }}
    />
  );
}
```

See [Row reorder](?path=/story/modules-datatable--row-reorder).
Transfer and DataTable expose `classNames.dragHandle` and `classNames.dragOverlay`;
DataTable also has `classNames.reorderCell`. Their ordinary selection, search,
form and table APIs continue to work when no plugin is supplied.
