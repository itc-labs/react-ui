# Components

Primitive trình bày độc lập nghiệp vụ, hỗ trợ native props và className override qua cn().

## Tag tones

<Canvas of={Tags.AllTones} />

Tag là nhãn; onClick hoặc selected bật tương tác dạng button. Trạng thái thiếu dữ liệu dùng neutral; stale dùng warning; chỉ dùng success khi có kết quả đã xác nhận.

## Card slots

<Canvas of={Cards.WithSlots} />

Title, description, action, content, footer là các vùng riêng. Card dùng section + heading h2; khi nhúng sâu cần cân nhắc hierarchy của page.

## Skeleton

<Canvas of={Skeletons.LoadingCard} />

Skeleton là decorative aria-hidden. Container cung cấp role=status và text dành cho screen reader; motion-safe tôn trọng reduced motion. Không dùng dữ liệu giả thay cho trạng thái loading.

## Progress

Thanh và vòng tiến độ hiển thị value/max hoặc trạng thái chưa xác định. Nhãn và giá trị hỗ trợ ngôn ngữ của UIProvider.
