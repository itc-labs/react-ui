# Icons

The catalog contains 651 names in Outline and Bold variants. Use leaf glyph imports for a few icons, or register the full catalogs to resolve names through `Icon`. See [Theming](?path=/docs/guides-theming--docs) for provider configuration and [Entry points & bundle size](?path=/docs/reference-entry-points-bundle-size--docs) for import boundaries.

## Import individual glyphs

Leaf imports load the glyphs you select and need no catalog registration. Direct glyph components are independent of `UIProvider` icon settings.

```tsx
import { Icon } from '@itclabs/react-ui';
import { SearchIcon } from '@itclabs/react-ui/icons/outline/search';
import { SearchIcon as SearchBoldIcon } from '@itclabs/react-ui/icons/bold/search';

export function Example() {
  return (
    <>
      <SearchIcon size={24} className="text-brand-700" />
      <SearchBoldIcon size={24} label="Search" />
      <Icon glyph={SearchIcon} size={20} label="Search" />
    </>
  );
}
```

`Icon glyph={...}` uses the provider's size and stroke width defaults unless overridden. A direct glyph import uses its own SVG defaults. `className` controls color and other styles independently of size and variant. Icons are decorative (`aria-hidden`) unless given a `label`. `IconButton` owns the button's accessible label.

## Resolve names with catalog registration

By default, `Icon` loads only the 35 names needed by kit controls, in both variants. `IconName` and `iconNames` still describe all 651 names. An unregistered name throws an error with configuration instructions.

```tsx
'use client';
import { Icon, IconButton, UIProvider, defineTheme } from '@itclabs/react-ui';
import { outlineCatalog, boldCatalog } from '@itclabs/react-ui/icons/catalog';

const theme = defineTheme({
  icons: { packs: { outline: outlineCatalog, bold: boldCatalog } },
});

export function Example() {
  return (
    <UIProvider theme={theme}>
      <Icon name="search" />
      <Icon name="search" variant="bold" />
      <IconButton icon="delete" iconVariant="bold" label="Delete" />
    </UIProvider>
  );
}
```

Register both catalogs to browse or use every name in either variant. Prefer leaf imports when you need only a few additional icons.

## Variant and size defaults

Set `icons.variant` to `outline` or `bold` through `defineTheme`. Per-icon `variant` and control `iconVariant` props select a variant for that use. Set `icons.size` and `icons.strokeWidth` for provider defaults; explicit icon props take priority. Without configuration, `Icon` uses size 16 and stroke width 1.75. Stroke width does not turn a filled glyph into an outline glyph.

Every name is available in both variants. There are 288 true source-library pairs. Another 359 names have only an outline glyph, reused unchanged in Bold and marked as outline-only in the catalog. Spinner and the three sort chevrons are neutral glyphs shared across variants. Bold is never simulated by increasing stroke width.

## Custom packs and overrides

Use `defineIconPack` to build a pack from selected glyphs. Register it under a key matching its `id`, then choose it with `defaultPack` or an explicit `pack` prop. Overrides replace semantic names when neither `pack` nor `variant` is explicit.

```tsx
'use client';
import { defineIconPack, defineTheme, Icon, UIProvider } from '@itclabs/react-ui';
import { SearchIcon } from '@itclabs/react-ui/icons/outline/search';
import { SearchIcon as SearchBoldIcon } from '@itclabs/react-ui/icons/bold/search';

const appPack = defineIconPack('app', { search: SearchIcon });
const theme = defineTheme({
  icons: {
    variant: 'bold',
    size: 20,
    packs: { app: appPack },
    defaultPack: 'app',
    overrides: { search: SearchBoldIcon },
  },
});

export function Example() {
  return (
    <UIProvider theme={theme}>
      <Icon name="search" label="Search" />
      <Icon name="search" pack="app" label="Search" />
      <Icon name="search" pack={appPack} size={24} label="Search" />
    </UIProvider>
  );
}
```

Resolution follows these rules:

- An explicit `glyph` wins.
- Without an explicit `pack` or `variant`, a theme override wins over pack lookup.
- Pack selection uses an explicit pack object/string, then explicit `variant`, then theme `defaultPack`, then theme `variant`, then `outline`.
- If the selected pack lacks a name, lookup falls back to the explicit or theme variant's registered pack, then that variant's built-in control glyphs. An unknown explicit pack string throws.

Nested providers merge packs and overrides while inheriting other icon settings. `defineTheme` validates pack IDs and positive size/stroke width values, then snapshots and freezes the settings. For application-specific semantic names, `UIIconNames` supports TypeScript module augmentation.

## Browse the catalog

<Canvas of={Icons.Playground} />

Filter by 18 categories or search names and aliases such as search, trash, and eye. Select a variant, then activate a tile to copy its direct import. The catalog renders 80 tiles at a time; use the load-more control to display the next group. Each tile supports Tab and Enter/Space.

The catalog reports a successful copy only after the Clipboard API succeeds. If copying is blocked, it selects the code for manual copying.

Illustrations are separate artwork, imported from `@itclabs/react-ui/illustrations`; they are not icon packs. See [Catalog](?path=/docs/reference-catalog--docs).
