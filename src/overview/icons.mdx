# Icon

Một bộ icon chung: **651 tên, hai chế độ Outline và Bold**. Lọc theo 18 nhóm; tìm tên hoặc alias như search, trash, eye; đổi variant rồi bấm icon để copy import trực tiếp. Không cần chọn thư viện nguồn. Catalog hiện 80 ô mỗi lần; bấm Xem thêm để tải tiếp.

## Hai variant

<Canvas of={Icons.Variants} />

Mỗi tên có mặt ở cả hai variant. Spinner và ba trạng thái chevron sort là glyph trung tính, giữ nguyên ở cả hai kiểu. 288 tên có cặp thật từ thư viện nguồn. Với 359 tên chỉ có Outline, cả hai chế độ dùng chung glyph Outline và catalog ghi “Chỉ có Outline”; không giả bold bằng cách tăng stroke-width.

## Cách dùng

Icon mặc định chỉ nạp 34 tên dùng trong controls của kit, có cả Outline/Bold. Để tra cứu toàn bộ 651 tên, đăng ký hai catalog trong UIProvider như ví dụ dưới. Nếu chỉ cần vài icon bổ sung, ưu tiên import từng glyph và dùng `glyph={SearchIcon}`; không cần đăng ký catalog. IconName và iconNames vẫn đủ 651 tên. Tên chưa đăng ký báo lỗi kèm hướng dẫn cấu hình. Theme overrides, custom packs/defaultPack và thứ tự ưu tiên glyph/pack/variant vẫn được giữ trong từng provider.

<Source language="tsx" code={`import { Icon, IconButton, UIProvider, defineTheme } from '@itclabs/react-ui';
import { outlineCatalog, boldCatalog } from '@itclabs/react-ui/icons/catalog';

const theme = defineTheme({ icons: { packs: { outline: outlineCatalog, bold: boldCatalog } } });

export function Example() {
  return (
    <UIProvider theme={theme}>
      <Icon name="search" />
      <Icon name="search" variant="bold" />
      <IconButton icon="delete" iconVariant="bold" label="Delete" />
    </UIProvider>
  );
}
`} />

Đặt variant mặc định một lần qua `defineTheme({ icons: { variant: 'bold' } })` trong UIProvider. Props variant/iconVariant ghi đè cho từng chỗ dùng. className và size vẫn tùy chỉnh độc lập. IconButton sở hữu accessible label của nút; icon trang trí mặc định aria-hidden.
